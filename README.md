# PlataformaCreditos

Aplicación web desarrollada con ASP.NET Core MVC (.NET 8).

## Funcionalidades
- Registro y login de usuarios (Identity)
- Gestión de solicitudes de crédito
- Panel de analista con aprobación/rechazo
- Validaciones de negocio
- Uso de Redis para cache y sesiones

## Tecnologías
- ASP.NET Core MVC
- Entity Framework Core
- SQLite
- Redis
- Render (deploy)
- GitHub
